# فواتير إيال — Eyal Invoices (Offline)

أداة فواتير وعروض أسعار مستقلة لإيال لإدارة الفعاليات. **ملف واحد، تعمل بدون إنترنت بالكامل**، بدون سيرفر وبدون اشتراك.

## التشغيل
1. نزّل الملف `Eyal-Invoices.html`.
2. افتحه بـ Chrome أو Edge أو Safari (دبل كلك).
3. ادخل **الإعدادات** وعبّئ: الرقم الضريبي، السجل التجاري، الحساب البنكي، وارفع الشعار.

ضع الملف في مكان ثابت (مثلاً `Documents/Eyal`) وافتحه دائمًا من نفس المكان بنفس المتصفح، لأن البيانات مرتبطة بالمتصفح ومسار الملف.

## المزايا
- **عروض أسعار ← فواتير** بضغطة، مع ربط رقم العرض داخل الفاتورة.
- **فاتورة ضريبية / مبسطة تلقائيًا**: إذا للعميل رقم ضريبي تطلع «فاتورة ضريبية»، وإذا ما عنده تطلع «مبسطة».
- **QR متوافق مع هيئة الزكاة والضريبة والجمارك (المرحلة الأولى)**: يتضمن اسم البائع والرقم الضريبي والتاريخ والإجمالي والضريبة بصيغة TLV.
- **المبلغ كتابةً** بالعربي (تفقيط).
- **طباعة / PDF** بمقاس A4 بهوية إيال (عربي + إنجليزي).
- **لوحة تحكم**: إجمالي المفوتر، المحصّل، المستحق، المتأخرة، و**ملخص الضريبة لكل ربع** جاهز للإقرار.
- **العملاء**: حفظ تلقائي، إجمالي التعامل والمستحق لكل عميل.
- **تصدير CSV** للمحاسب، و**نسخ احتياطي/استعادة** بملف JSON.

## مهم: النسخ الاحتياطي
البيانات محفوظة في المتصفح على هذا الجهاز فقط. لو مسحت بيانات المتصفح أو غيّرت الجهاز تضيع.
الأداة تنبّهك إذا مرّ أكثر من 7 أيام بدون نسخة. خذ نسخة أسبوعيًا واحفظها في الإيميل أو iCloud أو فلاش.
لنقل البيانات لجهاز ثاني: نسخة احتياطية ← افتح الأداة على الجهاز الجديد ← الإعدادات ← استعادة.

## تنبيه نظامي
الأداة تغطي متطلبات **المرحلة الأولى** من الفوترة الإلكترونية (الإصدار). إذا شملت هيئة الزكاة منشأتك في **المرحلة الثانية (الربط والتكامل)** فيلزم نظام مربوط بمنصة «فاتورة»، وهذا غير ممكن لأداة تعمل بدون إنترنت.

## للمطوّر
